# Vidéo

| Fichier | Usage |
|---|---|
| `altervnc-carte-titre-*-1080p.png`, `-4k.png` | Cartes titre fixes, fond clair ou sombre (SVG source à côté) |
| `altervnc-intro-clair-1080p.mp4`, `altervnc-intro-sombre-1080p.mp4` | Intro animée : le symbole se monte pièce par pièce, puis le nom et le slogan |
| `altervnc-symbole-anime-alpha.mov` | Symbole animé sur fond transparent, ProRes 4444 (montage) |
| `altervnc-symbole-anime-alpha.webm` | Même animation en VP9 avec transparence (web) |
| `calques/` | Une image par pièce, dans l'ordre d'animation : écran, écran du Mac, tige et pointe de la flèche, pied |
